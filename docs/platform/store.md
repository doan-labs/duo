# Store

The App Store app becomes real. It reads one index, installs bundles, and shows
updates. No backend, no accounts.

## CDN layout

```
cdn/
  index.json                      mutable, Cache-Control: max-age=60
  apps/<id>/<version>/index.html  immutable app document
  apps/<id>/<version>/index.js    immutable
  apps/<id>/<version>/index.css   immutable
  apps/<id>/<version>/icon-*.png  immutable, every size CI generated
  shell/latest.json               Tauri updater, see updates.md
  shell/<version>/*.dmg|.msi|.AppImage
```

Nothing under a published app/version changes. A release includes every script,
stylesheet, icon, and referenced asset. Publish the catalog only after the
complete release is available. Persistent offline storage and verification
are separate from HTTP caching and still need a loader design.

## index.json

Generated by CI from manifests on `main`. Illustrative metadata only: runtime
compatibility and release-history fields remain to be specified in the SDK schema.

```json
{
  "apps": {
    "dev.example.tides": {
      "name": "Tides", "version": "1.2.0", "lane": "community",
      "tier": "iframe", "size": 18400,
      "author": "Ada", "repo": "...", "summary": "...", "category": "Weather",
      "widgets": ["small"], "cover": false
    }
  }
}
```

The shell fetches it at boot and every hour while open. Offline, the last copy
in local storage stands. The final catalog must support selecting compatible
releases; a latest-only entry cannot provide older-shell update history. The
example size is a placeholder, not a measured budget for bundled React apps.

## Shelf

Today, Games, Apps, Updates, Search, the real tabs. Today is a curated list in
the repo (`packages/apps/TODAY.md`, a list of ids). Apps is the index sorted
by lane then name, with the Community ribbon on community entries. Search is
name and summary, client side.

## Install

GET → progress → OPEN, as the current fake button does, but the progress is the
real fetch. On success the manifest lands in `os.installed`, the icon appears in
the first free cell of the inner display, and the complete bundle is persisted. Baked apps show
OPEN and never GET.

Requires: the Store checks the SDK-defined host protocol/API requirement against
the running shell. The app's bundled kit version is not the host requirement.
When an appropriate newer shell is available, offer a page reload on web or
Software Update on desktop. An open browser tab can still run an old shell.

## Updates tab

Compare installed versions with compatible catalog releases. Each newer entry is a row
with the version, the size and the release note, which is the first line of
the app's `CHANGELOG.md` (CI copies it into the index). Update All at the top.
The App Store icon badges the count; Settings badges when a shell update waits.

Auto-update is a toggle in Settings, on by default: apply on the next launch
of the app, not while it is open.

## Uninstall

Long-press on the home screen, Remove App, the real two-step. Removes the
registry entry, the cached bundle, and `os.storage` under that id. Close active
frames and bridge connections before deleting their storage. Baked apps
offer Remove from Home Screen only.
