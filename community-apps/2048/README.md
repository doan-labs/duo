# 2048

2048 is a touch-friendly number-merging puzzle for Duo. Slide the board with the arrow controls, a keyboard, or a swipe on the game board. Matching tiles merge into larger numbers; reach 2048 to win.

The same board is usable on the inner display and the cover display. The cover keeps the complete 4 × 4 board visible and places the directional controls below it so the game does not depend on a keyboard.
