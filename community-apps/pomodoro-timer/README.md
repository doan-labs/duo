# Pomodoro Timer

Pomodoro Timer is a fold-aware focus timer for Duo. The inner display gives the
countdown and timeline room to breathe with the controls alongside the card,
while the cover stacks them simple enough to use one-handed.

Start a 25-minute focus session, pause it, reset it, or skip to a five-minute
break. Folding the phone mid-block hands the same countdown to the other
display: a running timer arrives with its end time intact, a paused one with
its remaining seconds.
