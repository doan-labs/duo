# Habit Streaks

Habit Streaks keeps three small daily habits close at hand. Tap a habit when it
is done, see the current streak, and return tomorrow without losing your
progress. Durable history stays in the app's private storage, while today's
checkmarks mirror through the session, so completing a habit on one display
continues on the other after a fold.

The cover view is intentionally compact so checking off a habit takes one tap.
Unfolded, the app widens into a rail beside the habit list.
