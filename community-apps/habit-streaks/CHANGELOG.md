# Changelog

## 1.1.0

- Redesigned the app on the UI kit token scales: a dark arcade look with a
  green glow, a glass completion chip, and Dynamic Type sizes throughout.
- Added a wide layout for the inner display - brand, counter and hint sit
  beside the habit list - while the cover keeps the compact stack.
- Added motion: a staggered list entrance, a streak pulse on completion and
  an all-done celebration, all off under reduced motion.
- Today's checkmarks now sync through session storage, so folding the phone
  hands the same day to the other display; history still lives in app
  storage.
- Bottom padding clears the home indicator.
