# Wordle Mini

Wordle Mini is a six-guess daily word puzzle for Duo, styled like a retro CRT
cabinet: pixel-bevel tiles in a dithered board well, chunky raised keys, a
marquee header, a blinking prompt caret, and a scanline overlay.

Use the physical keyboard or the on-screen keyboard. On the wide inner display
the board and keyboard sit side by side; the cover keeps a compact stack, and
both layouts clear the home indicator.

The daily word is deterministic for the current date and does not require a
network connection. Submitted guesses and the day's result persist across
relaunches, and the in-progress attempt syncs through the app session, so
folding the phone hands the same puzzle - mid-guess, half-typed row included -
to the other display.
