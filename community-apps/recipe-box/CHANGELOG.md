# Changelog

## 1.0.0

- Save, edit and delete recipes with a name, a note, ingredients and ordered
  steps.
- Check ingredients off while you prep; checks persist between sessions.
- Step-by-step cooking mode with progress bar, previous/next controls and a
  tap-to-jump step list; the current step persists so cooking can pause.
- Fold handoff: the open screen (list, recipe, cooking or an in-progress edit)
  syncs through session storage, so the other display continues in place.
- Two sample recipes on first launch; a plain empty state once everything is
  deleted.
