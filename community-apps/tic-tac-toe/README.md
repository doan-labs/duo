# Tic-Tac-Toe

Tic-Tac-Toe is a two-player pass-and-play game for Duo. Take turns on the
three-by-three board, reset the round, and keep a running win count for X and O.

On the inner display the controls ride a rail beside the board; on the cover
they stack under it. Folding the phone mid-round hands the same match - board,
turn, and tally - to the other display, so a game started on the cover
continues unfolded without losing a move.
