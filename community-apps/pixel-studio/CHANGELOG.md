# 1.0.0

First release: a pixel-art editor on 16 x 16 and 32 x 32 canvases with a token-colour
palette, paint, fill, erase and eyedropper tools, stroke-level undo/redo, a confirmed
clear, live pixel preview and a named local gallery. The working draft and undo history
survive folding and relaunch through app storage and the session mirror.
