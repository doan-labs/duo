# 1.1.0

Rebuild Notes to match Apple's: a rich-text document model behind a block
editor (Title, Heading, Subheading, Body, Monostyled, Block Quote, bold,
italic, underline, strikethrough, bulleted, dashed and numbered lists with
indent, tappable checklists, tables with growing rows and columns, inline
photos and auto-linked URLs), custom undo and redo, find-in-note with live
highlights, and a Markup canvas with inks, widths, eraser and undo kept beside
the document. Notes pin, lock behind the side button's double-press, move
between folders and drop into Recently Deleted with a 30-day clock, a recover
path and media cleanup on final delete. The folders rail gains iCloud,
user folders with rename and delete, the bin and a #tag strip mined from the
documents; the list gains a Pinned section, date groups, a gallery view,
sort orders, search and per-note menus; and the folded phone walks
Folders, list, note.

# 1.0.0

Run Notes in an isolated document with persistent text, shared session navigation
and explicit saving and failure states.
