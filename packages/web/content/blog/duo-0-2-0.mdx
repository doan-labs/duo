One rule for every one: **a row is real, or it is not there.** So the mocks we could not make honest (YouTube, Watch, the iTunes Store, Find My) are gone, and the rest talk to the real world through keyless services.

### Maps is squares

Maps draws real OpenStreetMap tiles. It only asks for the tiles under the glass, and a zoom between levels scales them instead of reloading. This runs the app's own code:

<TileDiagram />

Search is Photon and routes are FOSSGIS OSRM, one server per mode: the public demo quietly routes everything as driving.
