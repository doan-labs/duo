# video

The home page's hero loop: an abstract iPhone Duo folding open, the app handing over from the cover to
the inner display, then the title. Remotion, 1600x900, 8 s, seamless (the last frame matches the first).

Not a Bun workspace member — it has its own lockfile. `bun install` here once, then
`bun run render` (→ `../public/hero.mp4`), `bun run render:webm`, `bun run still` (→ `../public/hero-poster.jpg`),
or `bun run dev` for the Remotion studio.
